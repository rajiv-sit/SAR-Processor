# SAR-Processor

This repository contains the C++23 SAR IQ-to-image processing pipeline ported from
the original MATLAB codebase. The project is structured around modular components
for SarTape ingestion, RPF parsing, back-projection, PTA analysis, and RTO display.

See `md/architecture.md` and `md/milestones.md` for the implementation plan and progress.
